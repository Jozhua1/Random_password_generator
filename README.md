# 🔐 Password Generator Web App

A secure and interactive password generator built with Flask and vanilla JavaScript, allowing users to generate strong passwords, save them, and manage them with a master password vault.
## 🛠 Technologies Used
Backend: Python, Flask<br>
Frontend: HTML, CSS, JavaScript<br>
Storage: Browser localStorage (for saved passwords and master password)<br>

## 📍 The problem and solution
Problem: I have a hard time comming up with hard passwords for my social accounts to keep them secure and keep them all the different passwords in one place.<br>
**Solution:**  Random password generator so i can make hard passwords anytime,quick,easy, and can be found in one place so i dont loose it.<br>

## ✨ Features
Generate strong passwords up to 69 characters<br>
Save passwords with custom labels<br>
Password vault secured with a master password<br>
Edit and delete saved passwords<br>
Change master password anytime<br>

## 🔖 Future Improvements
Add password strength indicator<br>
Allow export/import of saved passwords securely<br>
Use backend database for cross-device sync<br>

## 🚦 Running the Project

1. Clone the repository
2. Install dependencies: `npm install`
3. Run development server: `npm run dev`
4. Open `http://localhost:5000` in your browser
